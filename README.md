# Monetize Marketing skills

Agent skills for Claude Code, Cursor, Codex and any tool that reads `SKILL.md` files. They teach the AI the Monetize Marketing workflow so it uses the [MCP tools](https://github.com/monetizemarketing/mcp) in the right order: mission first, Brain second, then research, then build, then save to the Library.

## Install

```bash
npx skills add monetizemarketing/skills
```

Claude Code without the skills CLI: copy `monetize-marketing/` into `.claude/skills/` in your project.

## Skills

| Skill | Use when |
|---|---|
| [`monetize-marketing`](monetize-marketing/SKILL.md) | Any task that touches your Monetize Marketing membership: your mission, your Brain, training, prompts, skills, routines, the Library, the shop. |

Requires the Monetize Marketing MCP connected and signed in. Not a member yet? Start at [monetizemarketing.com](https://monetizemarketing.com).
